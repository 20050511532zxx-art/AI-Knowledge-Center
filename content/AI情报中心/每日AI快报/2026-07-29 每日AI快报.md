## 二、新发现 AI 工具或模型

### OpenAI 语音转文字模型新快照

OpenAI 于 2026-07-28 在 API Changelog 公布三个语音转文字模型快照：

- `gpt-4o-mini-transcribe-2026-07-28`
- `gpt-4o-transcribe-2026-07-28`
- `gpt-4o-transcribe-diarize-2026-07-28`

官方说明新快照提升了语音转文字的准确性与可靠性。其中 diarize 版本适合需要区分不同说话人的转写场景。由于这是 OpenAI API 模型更新，不将其误写为 [[ChatGPT]] 客户端功能更新。

- 官方来源：https://platform.openai.com/docs/changelog

## 三、价格及套餐变化

### Cursor 在印度推出 Start 套餐

Cursor 于 2026-07-28 发布面向印度用户的 Start 个人套餐，官方页面列示价格为每月 ₹650，包含 Pro 模型访问和比免费 Hobby 套餐更多的 Agent 使用量。

该变化属于地区限定套餐，不代表 Cursor 在其他国家或地区同步调整价格。中国团队如需采购，仍应以账号所在地区的官方定价页为准。

- 官方来源：https://cursor.com/changelog/cursor-start

## 五、与全域电商运营相关的更新

### Google Docs 可通过 Gemini 生成图片和可编辑图表

Google 于 2026-07-28 宣布，用户可在 Docs 中使用 Gemini 创建或改进图片，并生成可编辑图表。对电商运营团队的价值包括：

- 在活动方案和经营报告中快速制作流程图、概念图和数据说明图。
- 根据文档上下文生成辅助视觉内容，减少在多个设计工具之间切换。
- 生成后继续编辑图表，而不是只能插入不可修改的静态图片。

该功能分阶段推出，当前不应视为所有 Google Workspace 账号均已可用。

### Google Docs 评论可转为 Gemini 行动项

Google 同日宣布，用户可在 Docs 评论中提及 Gemini，把反馈转为行动项并协助完成文档修改。对商品文案、活动策划和跨部门评审流程，可用于把评论直接转成待处理任务，减少人工整理反馈。

该功能按官方发布节奏逐步开放，企业管理员仍需核对版本、地区和管理设置。

- 官方来源：https://workspaceupdates.googleblog.com/2026/07/
