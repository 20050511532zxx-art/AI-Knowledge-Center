## 1. 产品概述与背景

### 1.1 什么是 AutoClaw

AutoClaw（中文名：澳龙）是智谱（Zhipu AI）于 2026 年 3 月 10 日发布的本地化 AI Agent 工具，它是 OpenClaw（小龙虾）的桌面客户端版本，定位为"人人可用的本地 AI 助手"。

AutoClaw 的核心理念是让 AI 技术走进千家万户，通过本地化部署的方式，用户可以在自己的电脑上拥有一套完整的 AI 自动化工作流，无需依赖云端服务，数据本地处理，隐私安全有保障。

### 1.2 AutoClaw 与 OpenClaw 的关系

| 特性 | OpenClaw（命令行版） | AutoClaw（桌面客户端） |
| --- | --- | --- |
| 部署方式 | 需要手动配置环境 | 一键安装 |
| 界面 | 命令行界面 | 图形化界面 |
| 适合用户 | 技术人员、开发者 | 普通用户 |
| 安装难度 | 较高 | 简单 |
| 预置 Skills | 需手动安装 | 50+ 开箱即用 |

### 1.3 核心产品定位

```text
传统 AI 云服务     →     AutoClaw 本地部署
       ↓                       ↓
数据上传云端           数据本地处理
隐私风险高               隐私安全
依赖网络连接             离线可用（部分功能）
```

## 3. 安装与登录

### 3.1 系统要求

| 组件 | 最低要求 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Windows 10 64位 | Windows 11 |
| 内存 | 8 GB | 16 GB |
| 存储空间 | 5 GB 可用空间 | 10 GB 以上 |
| 网络 | 需联网（验证/下载模型） | 宽带 |

### 3.2 Windows 安装步骤

步骤 1：下载安装包

1. 访问官网：https://autoglm.zhipuai.cn/autoclaw/
1. 点击「立即下载」按钮
1. 选择 Windows 版本
1. 下载完成后，双击打开 .exe 安装包
步骤 2：运行安装程序

```text
安装向导界面：
┌─────────────────────────────────────┐
│         AutoClaw 安装向导             │
│─────────────────────────────────────│
│  欢迎使用 AutoClaw 安装程序           │
│                                     │
│  [下一步(N) >]                        │
└─────────────────────────────────────┘
```

1. 点击「下一步」
1. 阅读并同意许可协议
1. 选择安装路径（建议默认）
1. 点击「安装」，等待完成
步骤 3：首次启动

1. 安装完成后，点击「完成」
1. AutoClaw 会自动启动
1. 首次启动需要初始化环境，请耐心等待
### 3.3 macOS 安装步骤

步骤 1：下载安装包

1. 访问官网下载 macOS 版本
1. 打开下载的 .dmg 文件
步骤 2：安装应用

1. 将 AutoClaw 拖入「应用程序」文件夹
1. 首次打开时，如果提示「无法验证开发者」：
步骤 3：启动应用

1. 在 Launchpad 中找到 AutoClaw
1. 双击启动
### 3.4 账号登录

登录流程：

1. 打开 AutoClaw 应用
1. 界面显示登录页面
1. 输入手机号，点击「获取验证码」
1. 输入收到的短信验证码
1. 点击「登录」
> 注意：首次启动会自动初始化环境，请保持网络连接，耐心等待。

### 5.2 配置默认模型

1. 点击左上角「设置」图标
1. 进入「模型与 API」选项
1. 选择「默认模型」
1. 保存设置
方法二：对话切换

```text

/model deepseek-r1

AI 回复：

```

### 5.3 接入第三方模型 API

如果需要使用 DeepSeek、Kimi、GLM 等模型，需要自行配置 API Key：

配置步骤：

1. 打开「设置 → 模型与 API」
1. 点击「添加模型」
1. 填写配置信息：
| 配置项 | 说明 | 示例 |
| --- | --- | --- |
| 模型名称 | 给模型起个名字 | DeepSeek R1 |
| API 地址 | 模型提供商的 API 端点 | https://api.deepseek.com |
| API Key | 你的密钥 | sk-xxxxxxxx |
| 模型 ID | 具体使用的模型 | deepseek-reasoner |

配置示例：

```text
{
  "model": "deepseek-r1",
  "apiBase": "https://api.deepseek.com/v1",
  "apiKey": "sk-xxxxxxxxxxxxxxxx",
  "modelId": "deepseek-reasoner"
}
```

## 6. 工作区与权限管理

### 6.1 工作区概念

工作区是 AutoClaw 操作文件的根目录，AI 只能在此范围内读写文件，确保系统安全。

```text
工作区结构：
C:\Users\admin\AutoClaw_Workspace\
├── projects\          # 项目文件
├── documents\         # 文档资料
├── downloads\         # 下载文件
└── temp\             # 临时文件
```

### 6.2 工作区设置

1. 打开「设置 → 工作区」
1. 点击「更改工作目录」
1. 选择目标文件夹
1. 确认保存
### 6.3 权限控制

| 权限项 | 说明 | 建议 |
| --- | --- | --- |
| 限制文件访问 | 将 AI 操作限制在工作区内 | ✅ 开启 |
| 允许执行命令 | 允许 AI 执行终端命令 | ⚠️ 谨慎开启 |
| 允许网络访问 | 允许 AI 访问互联网 | 按需开启 |
| 执行前确认 | AI 执行操作前需人工确认 | ✅ 开启 |

### 6.4 沙箱路径配置

沙箱是更细粒度的文件访问控制：

```text
{
  "sandbox": {
    "enabled": true,
    "allowedPaths": [
      "C:/Users/admin/workspace",
      "D:/projects"
    ],
    "blockedPaths": [
      "C:/Windows",
      "C:/Program Files"
    ]
  }
}
```

> 安全建议：生产环境务必配置沙箱路径，防止 AI 误操作系统文件。

## 7. 对话式指令操作

### 7.1 基本对话流程

AutoClaw 的核心操作方式是自然语言对话：

```text
用户输入：
帮我整理一下桌面文件，按类型分类

AutoClaw 执行：
🔄 正在分析桌面文件...
🔄 正在按类型分类...
✅ 完成！已整理 127 个文件：
   - 文档资料: 35 个
   - 图片文件: 28 个
   - 代码文件: 22 个
   - 其他文件: 42 个
```

### 7.2 常用指令示例

| 指令类型 | 示例 | 说明 |
| --- | --- | --- |
| 文件整理 | "帮我整理下载文件夹" | 按类型/日期整理 |
| 代码开发 | "写一个 Python 爬虫" | 生成完整代码 |
| 数据分析 | "分析这份 Excel 报表" | 数据统计可视化 |
| 文档处理 | "把这份 PDF 转成文字" | 格式转换 |
| 网页操作 | "帮我查下这个网页内容" | 信息采集 |
| 写作创作 | "写一篇产品介绍文案" | 内容生成 |

### 7.3 对话技巧

原则：越具体越好

```text
❌ 差："帮我写点东西"

✅ 好："帮我写一篇 800 字的产品介绍文案，
     面向年轻用户，语言活泼有趣，
     主要介绍我们新推出的智能手环"
```

### 7.4 执行确认机制

为保障安全，AI 在执行敏感操作前会请求确认：

```text
⚠️ 执行确认

AI 计划执行以下操作：
• 删除文件: temp_old.zip
• 修改文件: config.json

[确认执行] [取消操作]
```

## 9. 飞书集成配置

### 9.1 飞书集成概述

AutoClaw 支持一键接入飞书，在飞书中直接调用 AI 能力，实现消息处理、文档管理、任务自动化。

### 9.2 飞书集成前提

| 前提 | 说明 |
| --- | --- |
| AutoClaw 账号 | 已完成登录 |
| 飞书企业账号 | 需要管理员权限 |
| API Key | 如使用自定义模型 |

### 9.3 飞书集成步骤

步骤 1：创建飞书应用

1. 访问飞书开放平台：https://open.feishu.cn/
1. 进入「开发者后台」
1. 点击「创建企业自建应用」
1. 填写信息并创建
步骤 2：添加机器人

1. 在应用详情页点击「添加机器人」
步骤 3：配置权限

| 权限名称 | 说明 |
| --- | --- |
| im:message | 消息相关权限 |
| im:chat | 群聊相关权限 |
| im:message.group_at_msg | 群 @消息 |
| contact:user.base | 联系人基础信息 |
| drive:file | 云盘文件管理 |

步骤 4：在 AutoClaw 中配置飞书

1. 打开 AutoClaw「设置 → IM频道」
1. 选择「飞书」
1. 填写飞书应用的 App ID 和 App Secret
1. 配置接收消息的群聊
步骤 5：发布应用

1. 回到飞书开放平台
1. 点击「发布应用」
1. 创建版本并提交审核
### 9.4 飞书使用示例

在飞书群聊中：

## 10. 进阶管理：Skills 安装与卸载

### 10.1 SkillHub 技能市场

SkillHub 是 AutoClaw 的技能市场，提供更多自定义 Skills。

1. 打开 AutoClaw
1. 进入「技能市场」
1. 浏览和搜索 Skills
### 10.2 安装新 Skill

通过命令行安装：

```text
# 查看所有可用 Skills
openclaw skills list

# 查看技能详情
openclaw skills info <skill-name>

# 安装技能
openclaw skills install <skill-name>

# 卸载技能
openclaw skills uninstall <skill-name>
```

通过界面安装：

1. 打开「技能管理」
1. 点击「浏览市场」
1. 找到目标技能
1. 点击「安装」
### 10.3 推荐安装的 Skills

| Skill | 功能 | 安装命令 |
| --- | --- | --- |

## 11. 安全配置与风险控制

### 11.1 安全架构概览

```text
┌─────────────────────────────────────┐
│          安全防护层级                  │
├─────────────────────────────────────┤
│  1. 认证层：JWT Token 验证            │
│  2. 访问层：消息来源白名单             │
│  3. 执行层：操作前确认机制             │
│  4. 沙箱层：文件路径限制               │
└─────────────────────────────────────┘
```

### 11.2 JWT 认证配置

配置步骤：

1. 打开「设置 → 安全」
1. 开启「JWT 认证」
1. 设置 Token 密钥
1. 保存配置
配置示例：

```text
{
  "security": {
    "jwt": {
      "enabled": true,
      "token": "your-secret-token-here"
    }
  }
}
```

> 建议：在非局域网环境下务必开启 JWT 认证，防止未授权访问。

### 11.3 消息来源控制

dmPolicy 策略控制可向 AutoClaw 发送指令的主体：

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| whitelist（白名单） | 仅白名单来源可发送指令 | 高安全要求 |
| open（开放） | 任何来源均可发送指令 | 测试环境 |

配置示例：

```text
{
  "security": {
    "dmPolicy": "whitelist",
    "allowFrom": [
      "wechat:your-id",
      "feishu:群聊ID"
    ]
  }
}
```

> 警告：切勿在生产环境将 dmPolicy 设置为 open，否则任何人都可以控制你的电脑！

### 11.4 执行确认机制

| 配置项 | 说明 | 建议 |
| --- | --- | --- |

| 敏感操作确认 | 删除、执行命令等需确认 | ✅ 开启 |
| 超时时间 | 等待确认的超时时间 | 60 秒 |

## 13. 常见问题与故障排查

### 13.1 安装问题

Q1：Windows 安装失败，提示"无法验证开发者"

1. 右键点击安装文件 → 选择「属性」→ 勾选「解除锁定」→ 重新运行安装程序
Q2：macOS 无法打开，提示"无法验证开发者"

> 前往「系统设置 → 隐私与安全性」→ 点击「仍要打开」→ 输入密码确认

Q3：首次启动卡住不动

> 首次启动需要下载模型，请确保网络连接。等待 3-5 分钟。如果长时间无响应，尝试重启应用。

### 13.2 登录问题

Q4：收不到验证码

> 检查手机网络信号，确认手机未拦截短信，稍等片刻后重新获取

Q5：登录提示"账号异常"

> 确认使用的是官方版本，清除缓存后重试，联系官方客服

### 13.3 模型问题

Q6：提示"API Key 无效"

> 检查 API Key 是否正确复制，确认 API Key 有余额，检查 API 地址是否正确

Q7：模型响应很慢

> 检查网络连接，切换到响应更快的模型（如 Pony-Alpha-2），减少对话上下文长度

### 13.4 功能问题

Q8：飞书连接不上

> 确认飞书应用已发布，检查 App ID 和 Secret 是否正确，确认已配置正确的事件权限

Q9：文件操作失败

> 检查文件路径是否正确，确认工作区目录有写入权限，检查文件是否被其他程序占用

Q10：Skills 无法使用

> 检查 Skills 是否已安装，重启网关服务：openclaw gateway restart，查看 Skills 是否有更新

### 13.5 性能问题

Q11：内存占用过高

> 关闭不需要的项目，清理对话历史，重启 AutoClaw

Q12：响应速度变慢

> 检查网络状态，清理缓存：「设置 → 高级 → 清理缓存」，重启应用
