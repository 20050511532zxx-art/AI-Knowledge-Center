# AI工具每日监控规则

## 一、任务目标

每天检查：

1. AI工具档案中已有工具是否发布重要更新。
2. 最近24至48小时是否出现新的AI工具。
3. 是否发生模型、功能、API、价格或套餐变化。
4. 是否出现与全域电商运营有关的AI功能更新。
5. 将有效信息沉淀到AI工具数据库。

## 二、监控范围

优先检查：

- AI工具档案中已经存在的工具
- 国际主流AI公司
- AI编程工具
- AI图片和视频工具
- AI办公工具
- AI Agent和工作流工具
- AI搜索和数据分析工具
- 电商平台及其AI能力

重点关注：

- OpenAI
- Anthropic
- Google
- Microsoft
- Meta
- DeepSeek
- Perplexity
- Cursor
- GitHub Copilot
- Windsurf
- Midjourney
- Runway
- Canva
- Dify
- Coze
- Shopify
- Amazon
- TikTok Shop
- Shopee
- Temu
- Mercado Libre

## 三、允许使用的信息源

正式记录必须优先来自：

1. 官方更新日志
2. 官方Release Notes
3. 官方博客或新闻中心
4. 官方开发者文档
5. 官方帮助中心
6. 官方认证账号公告

媒体、自媒体、论坛和AI导航站可以用于发现线索，
但不能作为唯一正式来源。

## 四、需要记录的更新

记录以下内容：

- 新AI工具正式发布
- 新模型发布
- 重要功能上线
- API发布或重大变化
- 价格或套餐变化
- 使用额度或限制变化
- 产品改名、合并或停止服务
- 正式开放新地区或新用户群体
- 对电商运营有实际价值的AI能力

通常不记录：

- 普通营销文章
- 教程和案例文章
- 没有具体变化的宣传
- 无法由官方确认的传闻
- 轻微界面调整
- 重复发布的旧消息
- 单纯活动预告

## 五、已有工具更新规则

发现已有工具的重要更新时：

1. 找到“AI工具档案”中的对应文件。
2. 检查“更新记录”中是否已经存在。
3. 不得重复写入。
4. 在“更新记录”下追加新内容。
5. 不得覆盖历史内容。
6. 每条记录必须包含日期、更新类型、更新摘要和官方来源。

标准格式：

### YYYY-MM-DD

**更新类型：**

**更新内容：**

**官方来源：**

- 官方链接

## 六、新工具规则

新工具必须同时满足：

1. 有独立官方网站。
2. 已经正式发布或开放使用。
3. 有明确的AI功能。
4. 有清晰的使用场景。
5. 有官方发布信息。
6. 不是导航站、工具合集或纯内容网站。
7. 不是已有工具的小功能改名。

符合条件的新工具写入当天的“每日AI快报”。

暂时不要自动创建正式工具档案，
避免大量低质量工具进入数据库。

## 七、去重规则

写入前必须检查：

1. 对应AI工具档案的更新记录。
2. 最近7天的每日AI快报。
3. 当天的工具更新记录。
4. 官方公告标题、发布日期和链接。

同一个更新不得重复记录。

## 八、文件安全规则

1. 不删除任何历史文件。
2. 不覆盖历史更新。
3. 不修改无关文件。
4. 不编造信息。
5. 找不到官方来源时不正式收录。
6. 不自动更改现有工具名称。
7. 不自动合并工具档案。
