# 投稿分析知识库整理提示词

## 任务目标

读取本次指定的飞书投稿分析和原始投稿，将有效信息整理到正式 AI 情报知识库。

## 强制限制

1. 使用 Codex 自身能力，不调用 OpenAI API，不运行任何模型 API 脚本。
2. 不删除、移动或重命名任何已有文件。
3. 不修改 `feishu_sync.js`、`scripts/feishu/`、Quartz 配置、现有 AI 工具档案、旧工具更新记录或旧每日快报。
4. 只允许写入以下目录：
   - `content/AI情报中心/AI工具库/`
   - `content/AI情报中心/工具更新日志/`
   - `content/AI情报中心/行业动态/`
   - `content/AI情报中心/推荐测试/`
   - `content/AI情报中心/月度总结/`
   - `.runtime/codex/knowledge-state.json`
5. 不公开员工提交人姓名。
6. 不编造投稿、分析或已有档案中没有的信息。
7. 使用 UTF-8 无 BOM、LF 换行、标准 YAML frontmatter 和 Obsidian 双向链接。
8. 使用 `feishu_record_id + contentHash` 去重，同一版本不得重复追加。
9. 官方链接必须逐字存在于原始投稿、投稿分析或已有本地档案中。不得凭记忆补充 URL；只有官网首页时使用首页，并明确缺少对应更新公告。

## 参考资料

整理前读取：

- 本次指定的投稿分析 Markdown
- 对应的飞书原始 JSON
- `content/AI情报中心/AI工具监控规则.md`
- `content/AI工具档案/` 下与工具相关的现有档案
- 已经存在的五类知识库文件

## AI工具库

有明确工具名称、官方链接、AI能力和电商应用场景时，创建或更新：

`content/AI情报中心/AI工具库/<工具名称>.md`

文件必须包含：

- 工具名称
- 官方链接
- 工具类型
- 最新更新
- 电商应用场景
- 推荐部门
- 使用价值评分
- 风险与限制
- 相关资料

frontmatter 至少包含：

```yaml
---
title: 工具名称
type: ai-tool
tool_name: 工具名称
official_url: https://example.com
tool_type:
  - 工具类型
latest_update: YYYY-MM-DD
recommended_departments:
  - 运营
ai_value_score: 4
test_recommendation: 建议测试
status: active
---
```

已有工具文件只能合并和追加。最新更新中记录投稿分析链接与飞书记录 ID，不得重复写入相同 ID。

## 工具更新日志

按月创建或更新：

`content/AI情报中心/工具更新日志/YYYY-MM 工具更新日志.md`

按日期记录工具名称、更新类型、更新摘要、评分、测试建议、投稿分析链接、工具库链接和飞书记录 ID。

## 行业动态

只有信息属于行业政策、模型趋势、电商平台 AI 能力、商业模式、产品合并停服或通用技术趋势时，才写入：

`content/AI情报中心/行业动态/YYYY-MM 行业动态.md`

普通单一工具功能更新不得重复写入行业动态。没有有效行业动态时不创建空文件。

## 推荐测试

当评分不低于运行配置的最低分，并且结论为“建议测试”时，创建或更新：

`content/AI情报中心/推荐测试/YYYY-MM 推荐测试清单.md`

必须包含工具、测试目标、推荐部门、测试场景、验证指标、风险点、测试范围、投稿分析链接和飞书记录 ID。

## 月度总结

创建或更新：

`content/AI情报中心/月度总结/YYYY-MM AI情报月度总结.md`

根据知识库内实际文件汇总本月工具更新、行业动态、推荐测试、部门方向、重点风险和下一步行动。不得虚构数量。

## 无法正式入库

如果缺少明确工具名称、官方链接或电商应用价值，不创建正式工具文件。仍需在知识库状态中记录为 `skipped`，说明原因，不得伪造输出。

## 状态文件

完成全部文件写入后，合并更新 `.runtime/codex/knowledge-state.json`：

```json
{
  "schemaVersion": 1,
  "lastRunAt": "ISO-8601时间",
  "records": {
    "rec_xxxxx": {
      "contentHash": "投稿内容哈希",
      "status": "completed",
      "processedAt": "ISO-8601时间",
      "outputs": ["content/AI情报中心/AI工具库/工具名称.md"]
    }
  }
}
```

保留状态文件中的其他记录。只有文件全部写入成功后才能标记 `completed`。

## 完成报告

最终说明处理数量、创建文件、更新文件、跳过信息和所有输出路径。
