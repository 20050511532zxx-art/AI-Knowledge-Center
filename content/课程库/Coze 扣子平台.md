## 1. 平台概述

### 1.1 什么是 Coze 扣子

Coze 扣子是字节跳动推出的一站式 AI 智能体（Agent）开发与应用平台。其核心理念是「降低 AI 应用开发门槛」，通过无代码/低代码的方式，让即使没有编程背景的用户也能快速构建功能强大的 AI 智能体，并一键发布到飞书、抖音、微信、豆包等主流平台。

Coze 更像是一个 AI 应用的「智能工厂」，追求的是标准化、流程化和易用性。

### 1.2 平台版本

| 版本 | 适用人群 | 主要区别 |
| --- | --- | --- |
| 个人基础版 | 普通用户尝鲜 | 功能受限，不能部署 OpenClaw |
| 个人高级版 | 有高级需求的用户 | 可部署 OpenClaw，消耗算力积分 |
| 个人旗舰版 | 深度用户 | 更多额度和高级功能 |
| 企业标准版/旗舰版 | 团队/企业 | 团队协作、权限管理、API 调用 |

> 💡 普通用户想要在 Coze 上部署 OpenClaw 小龙虾，需购买个人高级版及以上版本。

### 1.3 访问地址

- 国际版 Coze：https://coze.com
- 国内版扣子：https://www.coze.cn

## 2. 核心概念

在深入使用前，需理解 Coze 的几个核心概念：

### 2.1 智能体（Agent）

智能体是 Coze 平台的核心产品，可以理解为具备语言理解和对话能力的 AI「大脑」：

- 理解用户的自然语言输入
- 分析用户意图和上下文
- 决定对话走向和响应策略
- 协调调用各种功能模块（插件、工作流、知识库）
### 2.2 工作流（Workflow）

工作流扮演「执行者」的角色，通过可视化编排实现复杂业务流程：

- 将多个节点串联成自动化流程
- 支持条件分支、循环、并行执行
- 可被智能体调用，实现复杂任务
### 2.3 知识库（Knowledge）

让 AI 智能体拥有「专业知识」或「私有数据」：

- 支持上传 PDF、Word、TXT、Excel、CSV 等文件
- 支持在线网页爬取（URL 导入）
- 支持 API 自动同步数据
- 智能分段（Chunking）处理，提升检索精度
### 2.4 插件（Plugins）

扩展 AI 能力边界的工具集，Coze 集成了60+ 官方插件，涵盖：

- 新闻阅读、旅行规划、生产力工具
- 图像理解 API、多模态模型
- 支持快速集成私有 API 为自定义插件
### 2.5 卡片（Cards）

用于定制智能体对话界面中的交互卡片，呈现结构化信息（如按钮、表单、数据展示等），提升用户体验。

### 2.6 变量（Variables）

在智能体或工作流中存储和传递数据，支持不同数据类型，实现跨节点/跨会话的状态保持。

## 4. 工作流（Workflow）

### 4.1 什么是工作流

工作流（Workflow）是通过可视化节点编排，将多个操作串联成自动化流程的工具。相比智能体的「问答式」交互，工作流更适合复杂、标准化的任务。

### 4.2 适用场景

- 数据处理与转换（格式转换、批量处理）
- 多步骤业务流程（内容生成→审核→发布）
- 定时任务与自动化（每天自动生成日报）
- API 调用串联（调用多个外部接口）
### 4.3 创建工作流

1. 工作台 → 左侧菜单 → 工作流
1. 点击「创建工作流」
1. 选择模板或从空白开始
1. 进入可视化编排界面
### 4.4 节点类型

| 节点类型 | 说明 |
| --- | --- |
| 大模型（LLM） | 调用 AI 模型进行文本处理 |
| 代码（Code） | 执行 Python/JS 代码片段 |
| 条件（Condition） | if/else 条件分支 |
| 循环（Loop） | for/while 循环执行 |
| 插件（Plugin） | 调用插件能力 |
| 知识库检索 | 从知识库中查询相关内容 |
| HTTP 请求 | 发起外部 API 请求 |
| 开始/结束 | 定义流程入口和出口 |

### 4.5 工作流编排示例

```text
【开始】→【大模型：提取关键词】→【知识库检索】
                                          ↓
                                   【条件：有无结果】
                                   ↓是              ↓否
                            【大模型：生成答案】  【大模型：通用回答】
                                          ↓
                                     【结束】
```

### 4.6 避坑指南

- ⚠️ 循环节点需设置退出条件，防止死循环
- ⚠️ HTTP 请求需注意超时设置（建议 ≥ 30s）
- ⚠️ 复杂工作流建议先在测试环境验证
- 💡 可以通过工作流市场复制他人的优质工作流

### 5.1 创建知识库

1. 工作台 → 左侧菜单 → 知识库
1. 点击「创建知识库」
1. 设置基本信息：
1. 选择数据类型：
### 5.2 数据导入方式

| 方式 | 说明 |
| --- | --- |
| 本地文件上传 | 支持 PDF、Word、TXT、Excel、CSV |
| 在线网页爬取 | 输入 URL，自动抓取网页内容 |
| API 自动同步 | 通过 API 接口定时同步外部数据 |

### 5.3 数据分段（Chunking）

分段设置是决定检索准确性的核心环节：

- 智能分段：AI 自动识别语义边界
- 固定长度分段：按字符数均分（如每 500 字符一段）
- 自定义分段：手动设置段落标记
> 💡 分段过长会导致信息密度不足，分段过短会丢失上下文。建议根据文档特点选择合适的分段策略。

### 5.4 知识库召回配置

- 召回数量：每次检索返回多少条（建议 3-5 条）
- 相似度阈值：低于此分数的结果将被过滤
- 召回模式：语义匹配 / 关键词匹配 / 混合
### 5.5 知识库在智能体中的使用

1. 打开智能体编辑页面
1. 在「知识库」配置项中添加已创建的知识库
1. 智能体会自动根据用户问题检索知识库并结合回答

## 9. AI 模型配置

### 9.1 模型选择策略

选择合适的模型需要考虑以下因素：

| 考虑维度 | 建议 |
| --- | --- |
| 使用场景 | 日常对话选豆包，技术场景选 DeepSeek |

| 质量要求 | 高质量要求选 GPT-4o、豆包旗舰版 |

### 9.2 模型参数配置

| 参数 | 说明 | 建议值 |
| --- | --- | --- |
| Temperature | 创造性/确定性（0-1） | 0.7（平衡） |
| Max Tokens | 单次最大输出 token 数 | 2048-4096 |
| Top P | 采样多样度 | 0.9（默认） |

### 9.3 专业版大模型添加

Coze 专业版支持添加自定义大模型：

1. 预览效果，可进一步用自然语言调整

## 12. OpenClaw 部署指南

### 12.1 什么是 OpenClaw

OpenClaw（小龙虾）是 Coze 平台上的一个 AI Agent，支持通过 Coze 云端部署，集成在飞书等平台中使用。

### 12.2 部署前提

- ✅ Coze 个人高级版及以上版本（需付费）
- ✅ 飞书账号（用于授权）
- ⚠️ 每次运行会消耗算力积分
### 12.3 部署步骤

#### 第一步：进入部署入口

1. 打开 [www.coze.cn](https://www.coze.cn)，右上角「免费开始」登录
1. 左侧菜单栏找到「扣子编程」，点击进入
1. 在右侧窗口最上方找到「部署 OpenClaw」
#### 第二步：创建小龙虾

1. 点击「部署」按钮进入部署页面
1. 目前 Coze 只支持：个人高级版、个人旗舰版、企业标准版及企业旗舰版
1. 选择版本：
1. 为小龙虾命名（点击笔头图标修改）
1. 点击「确定」完成创建
#### 第三步：飞书授权

1. 点击右上角「齿轮图标」进入设置
1. 找到飞书图标，点击「授权并创建」
1. 登录飞书完成授权（等待约 2 分钟）
1. 点击「去飞书对话」验证授权状态
#### 第四步：开始使用

1. 打开飞书，找到「开发者助手」
1. 开始与小龙虾对话
1. 每次对话会消耗算力积分，注意额度管理
### 12.4 常见问题

| 问题 | 解决方案 |
| --- | --- |
| 部署失败 | 检查网络连接，等待 1-2 分钟后重试 |
| 无法授权飞书 | 确认飞书账号状态，重新扫码授权 |
| 算力积分不足 | 在 Coze 平台充值或参与赠送活动 |
| 每个人只能创建一个 | 如需重新部署，先删除现有实例 |

## 13. 常见问题与技巧

### 13.1 常见问题

Q：Coze 免费版有哪些限制？

> 免费版可创建基础智能体，但不能部署 OpenClaw，高级插件和知识库额度有限。

Q：如何提升智能体的回答质量？

- 优化提示词（Prompt），结构越清晰效果越好
- 关联知识库，提供专业背景信息
- 添加合适的插件，扩展能力边界
- 使用工作流处理复杂任务
Q：知识库检索不准确怎么办？

- 调整分段策略，减小分段粒度
- 提高召回数量，获取更多候选
- 检查知识库数据质量，去除噪声
- 尝试不同的相似度阈值
Q：工作流执行失败怎么排查？

- 查看日志，找到失败的节点
- 检查 API 配置（URL、参数、认证）
- 确认节点输入数据格式正确
- 逐步单步调试，定位问题节点
Q：如何管理算力积分？

- 在 Coze 控制台查看使用明细
- 选择「省流版」降低单次消耗
- 参与官方赠送活动获取积分
### 13.2 使用技巧

1. 提示词优化：用 # 角色、## 技能、## 限制 等结构化格式，AI 理解效果更好
1. 插件组合：将多个相关插件组合使用，发挥「1+1>2」的效果
1. 知识库 + 工作流：先用知识库检索，再用工作流处理数据，效率翻倍
1. 善用开场白：配置合理的开场白和用户问题建议，降低使用门槛
1. 版本管理：发布前做好版本记录，方便回退
1. 复用模板：Coze 模板市场有大量优质模板，可直接复用或作为参考
