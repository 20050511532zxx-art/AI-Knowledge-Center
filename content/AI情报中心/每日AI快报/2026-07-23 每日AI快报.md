## 二、新发现AI工具或模型

### OpenAI Presence

- 发布方：OpenAI
- 类型：AI 原生远程协作设备
- 核心功能：理解会议空间和对话节奏，改善远程参与者的临场感与互动体验。
- 主要场景：跨城市团队会议、远程评审、客户沟通和混合办公协作。
- 业务判断：值得关注，但尚需核实购买方式、部署范围、数据处理规则和实际成本。

### Cursor Router

- 发布方：Cursor
- 类型：模型自动路由服务
- 核心功能：根据任务自动选择模型，在质量、速度和成本之间动态平衡，并提供 OpenAI 兼容接口。
- 主要场景：代码生成、复杂开发任务、企业内部多模型调用和成本控制。
- 业务判断：可能降低维护模型清单的成本，但仍需用真实任务验证稳定性。

### Kimi K2.7 Code

- 发布方：Moonshot AI / Kimi
- 类型：Agentic Coding 模型
- 核心功能：面向复杂代码任务、长流程开发和编程 Agent，并提供 API、Kimi Code 与开源模型渠道。
- 主要场景：代码生成、仓库级修改、自动化开发流程和技术团队辅助。
- 业务判断：对自建内部工具、批量处理数据或连接业务系统的团队更有价值，普通运营人员不必仅因模型发布立即迁移。

### Kimi Work

- 发布方：Moonshot AI / Kimi
- 类型：桌面 Agent
- 核心功能：在持续工作空间中读取本地资料、保持任务上下文并完成多步骤工作。
- 主要场景：资料整理、文件分析、报告生成、研究任务和跨文档工作流。
- 业务判断：可测试商品资料、运营报表和 SOP 处理，但涉及本地文件时必须先核实权限和数据保留规则。

## 四、API及开发者更新

### Cursor Router

- 提供 OpenAI 兼容接口，可减少接入多家模型时的接口改造工作。
- 建议用固定任务集测试质量、延迟、成本和失败率，再决定是否替代人工选模。

### GitHub Copilot 使用指标影响力仪表盘

- 企业和组织管理员可以集中观察 Copilot 的使用与采用趋势。
- 可用于判断账号是否真正被使用，并为培训、权限分配和续费决策提供依据。

### Gemini 3.6 Flash 接入 GitHub Copilot

- GitHub Copilot 付费用户可在模型选择器中使用 Gemini 3.6 Flash。
- 本条记录 Copilot 新增模型接入；模型本身已在 [[2026-07-22 每日AI快报]] 中记录。

### Kimi Code CLI 0.29

- 更新 Skills、Subagents、Worktrees 和 IDE 支持。
- 适合关注多 Agent 分工、并行开发和仓库级任务处理，但应限制代码仓库权限并保留人工审核。

## 五、与全域电商运营相关的更新

### 1. 用 Copilot 指标判断 AI 账号是否值得续费

- 企业可把活跃使用、采用趋势与实际交付结果结合，减少只买账号、不形成工作习惯的浪费。
- 电商团队可按运营、设计、数据和技术岗位分别设定指标，不能只用代码接受量代表全部业务价值。

### 2. 用桌面 Agent 整理商品资料和运营文档

- Kimi Work 的持续工作空间适合测试商品资料汇总、活动复盘、竞品材料整理和 SOP 生成。
- 涉及客户数据、供应商报价、未发布商品和内部经营数据时，应先脱敏并核实数据处理条款。

### 3. 用自动模型路由控制内部 AI 工作流成本

- Cursor Router 展示了“按任务自动选模型”的方向，可迁移到文案、数据清洗、客服质检和代码任务的多模型工作流。
- 不能直接采用官方节省比例作为企业预算依据，需要以自身任务集做对照测试。

### 4. 手机端跨应用 Agent 可能进入移动运营流程

- Gemini 在 Galaxy Z Fold7 AI Edition 上扩展跨应用能力，说明移动端 Agent 正从问答转向操作设备应用。
- 对移动办公、电商巡店、内容采集和差旅有潜在价值，但当前受设备、地区、应用支持和用户授权限制。

### 5. 编程 Agent 更适合连接业务系统，而非替代运营判断

- Kimi K2.7 Code 和 Kimi Code CLI 可用于搭建数据整理脚本、内部查询工具和自动化接口。
- 商品策略、价格决策、广告投放和客户承诺仍需业务人员负责，不能交给编程 Agent 自动执行。
