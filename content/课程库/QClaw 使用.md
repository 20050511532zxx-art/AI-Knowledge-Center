## 1. 什么是 QClaw？

### 1.1 产品定位

QClaw 是腾讯电脑管家官方出品的桌面 AI 助手，基于开源 OpenClaw（昵称"数字龙虾"🦞）框架打造，定位为零门槛本地 AI 智能体一键启动包。

2026 年 3 月 20 日，QClaw 正式开启全量公测，无需邀请码，用户通过官网下载最新版本，20 秒即可完成安装，并向"龙虾"下达指令。

### 1.2 QClaw vs OpenClaw

| 对比项 | OpenClaw（开源版） | QClaw（腾讯官方版） |
| --- | --- | --- |
| 安装方式 | 命令行/npm 安装，配置复杂 | 一键安装，图形界面，完全零代码 |
| 模型配置 | 需手动配置 API Key 和地址 | 内置国产大模型，开箱即用 |
| 渠道接入 | 需手动配置飞书/微信插件 | 微信扫码直连，一键绑定 |
| 技能安装 | 命令行安装，依赖网络 | SkillHub 一键安装，高速镜像 |
| Token | 完全自付 | 每日 4000 万免费 Token |
| 目标用户 | 开发者/技术爱好者 | 普通用户/小白用户 |
| 隐私 | 本地运行 | 本地运行，腾讯背书 |

> 一句话总结：QClaw = OpenClaw 的腾讯官方 GUI 包装版，让"养龙虾"变得像装微信一样简单。

### 1.3 官方背景与荣誉

- 出品方：腾讯电脑管家
- 官网：[https://qclaw.qq.com](https://qclaw.qq.com)（主站）
- 备份站：[https://claw.guanjia.qq.com](https://claw.guanjia.qq.com)
- 腾讯官方公众号：腾讯 QClaw 已与腾讯云深度整合，背靠腾讯安全体系

## 3. 安装与启动

### 3.1 系统要求

| 项目 | Windows | macOS |
| --- | --- | --- |
| 操作系统 | Windows 10 及以上 | macOS 11 (Big Sur) 及以上 |
| 处理器 | x64 架构 | Intel / Apple Silicon 均支持 |
| 内存 | 4GB 及以上（推荐 8GB） | 4GB 及以上（推荐 8GB） |
| 磁盘空间 | 2GB 可用空间 | 2GB 可用空间 |
| 网络 | 需要网络连接（下载安装包） | 需要网络连接 |

### 3.2 下载安装

下载地址（任选其一）：

| 地址 | 说明 |
| --- | --- |
| [https://qclaw.qq.com](https://qclaw.qq.com) | 主站（推荐） |
| [https://claw.guanjia.qq.com](https://claw.guanjia.qq.com) | 腾讯电脑管家备份站 |

Windows 安装步骤：

```text
步骤 1：下载安装包
→ 访问官网 → 点击"下载" → 选择 Windows 版本
→ 双击 .exe 安装包

步骤 2：一键安装
→ 出现安装向导 → 点击"出发咯"（龙虾钳图标按钮）
→ 安装路径建议选择 D 盘（避免 C 盘空间不足）
→ 等待安装完成（约 2 分钟，无需人工干预）

步骤 3：启动 QClaw
→ 安装完成后自动启动
→ 或从开始菜单/桌面快捷方式启动
```

macOS 安装步骤：

```text
步骤 1：下载安装包
→ 访问官网 → 点击"下载" → 选择 macOS 版本

步骤 2：安装
→ 将 QClaw 拖入"应用程序"文件夹
→ 首次打开：右键点击 QClaw → 选择"打开"
  （绕过 macOS Gatekeeper 安全验证）

步骤 3：等待部署
→ 首次运行会自动部署环境（约 2-5 分钟）
→ ⚠️ 中途不要关闭窗口！
```

### 3.3 首次启动配置向导

QClaw 图形界面提供了完整的配置向导，共 6 步：

#### 步骤 1：风险确认

阅读并确认权限风险声明 → 点击「确认」

#### 步骤 2：选择模型服务商

新手推荐：选择「免费试用」，使用内置国产大模型（无需填 API Key）

进阶用户：选择自定义模型

```text
选择模型服务商：千问 / DeepSeek / 混元 / 豆包 等
选择模型名称：根据服务商选择具体模型
输入 API Key：填入你从模型平台获取的 Key
```

#### 步骤 3：连接通信软件（可选）

选择要连接的 IM 渠道（可跳过，后续单独配置）：

| 渠道 | 配置内容 | 难度 |
| --- | --- | --- |
| 飞书 | App ID + App Secret | 中等 |
| 钉钉 | Client ID + Client Secret | 中等 |
| 企业微信 | AgentId + Secret | 简单 |
| 个人微信 | 扫码绑定 | 最简 |

#### 步骤 4：群聊策略（若已连接飞书/钉钉）

- 所有群聊：机器人响应所有群的消息
- 仅部分群聊（白名单）：输入群聊 ID，多个用逗号分隔
- 禁用群聊：仅响应私聊
#### 步骤 5：安装官方 Skills

系统会推荐官方 Skills 列表：

- 可按需选择需要的技能
- 也可选择「全部安装」
- 安装后可在 SkillHub 中卸载不需要的
#### 步骤 6：推荐功能

```text
QClaw额外推荐：
☑ 省钱模式（智能优化 Token 消耗）
☑ 恶意技能筛查（自动检测可疑 Skill）
☑ 虾灵感（内置提示词库，减少输入）
```

### 3.4 启动与状态确认

```text
✅ 安装成功的标志：
- QClaw 主界面正常打开
- 底部显示"微信未连接"或其他渠道状态
- 界面中有"微信连接"按钮
```

## 4. 微信连接配置

> 微信连接是 QClaw 最核心的功能，连接后即可通过手机微信远程操控电脑。

### 4.1 绑定微信（个人微信直连）

步骤：

① 打开 QClaw 主界面

② 点击左下角「微信连接」按钮

③ 界面显示绑定二维码

④ 打开手机微信 → 扫描二维码
⑤ 手机微信点击「确认绑定」/[继续连接]

⑥ 绑定成功：微信出现「QClaw助手」对话窗口

⑦ 电脑端显示「微信已连接」

绑定成功后：

- 微信聊天列表顶部出现「QClaw助手」或「ClawBot」
- 搜索「龙虾」或「Claw」可快速找到
- 直接在微信对话框发送自然语言指令即可操控电脑
### 4.2 使用微信远程操控

绑定成功后，离开电脑也能操控！在微信对话框直接发送：

```text
📁 文件操作
"帮我打开桌面的Q3报告.xlsx"
"把Downloads文件夹里的PDF都移到Documents"
"帮我整理桌面，按项目分类"

📊 Office 文档
"帮我把这份Excel第三列求和"
"写一份周报模板"
"把这份PPT转成PDF"

🌐 信息检索
"帮我搜索最近AI大模型最新进展"
"查一下深圳今天的天气"
"帮我调研竞品情况并整理成文档"

💻 开发任务
"帮我提交今天的代码改动"
"运行这个Python脚本"
"帮我review一下这个PR"

📧 邮件与日程
"帮我起草一封给客户的邮件"
"明天上午10点提醒我开会"
```

> ⏱ 提示：AI 需要思考、搜集、执行，偶尔慢一点，耐心等待结果更稳定。

### 4.3 微信使用注意事项

| 注意事项 | 说明 |
| --- | --- |
| ⚠️ 电脑需开机 | 远程控制要求电脑保持开机状态 |
| ⚠️ 关闭睡眠 | 需将电脑设置为从不进入睡眠，或使用唤醒功能 |
| ⚠️ 网络连接 | 电脑和手机均需联网 |
| 💡 图片发送 | 可在微信中直接发送图片给 QClaw 分析 |
| 💡 文件传输 | 支持发送文件给 QClaw 处理 |

### 7.2 企业微信接入（推荐企业用户）

优势：

- ✅ 可主动向用户推送消息（个人微信无法主动推送）
- ✅ 免费，无需认证
- ✅ 最多 1 分钟完成配置
配置步骤：

```text
① 访问 https://work.weixin.qq.com 注册企业微信（免费）
② 创建应用：应用管理 → 创建应用

④ 获取应用凭证：AgentId 和 Secret（在应用详情页）
⑤ 在 QClaw 中：
   设置 → 渠道管理 → 企业微信
   → 填写 AgentId 和 Secret
   → 点击连接
⑥ 配置成功，即可使用
```

## 8. 特色功能

### 8.1 龙虾像素工作室

> 龙虾像素工作室是 QClaw 的 AI 个性化定制功能，让你的 AI 助手拥有独特的"性格"和工作风格。

功能入口：QClaw 主界面 → 点击「像素工作室」或「个人设置」

可定制内容：

| 定制维度 | 可选设置 |
| --- | --- |
| 🎭 AI 性格 | 专业严谨 / 轻松幽默 / 简洁干练 / 详细耐心 |
| 💬 回复风格 | 长文详细 / 短句精炼 / 条理分明 / 口语化 |
| 🎯 专业方向 | 技术编程 / 商业办公 / 创意写作 / 日常助手 |
| 📝 工作习惯 | 主动建议 / 仅响应指令 / 自动优化表述 |
| 🗣 语言偏好 | 中文优先 / 英文为主 / 中英混搭 |

设置方法：

```text
① 在 SOUL.md 或 QClaw 设置中调整参数
② 或在对话中直接告诉 QClaw 你的偏好
   例如："我希望你回复时简洁一些，重点加粗"
③ QClaw 会自动学习并调整后续回复风格
```

### 8.2 定时任务（cron-skill）

QClaw 支持设置定时提醒和周期任务，让 AI 自动执行例行工作。

使用方式（通过 cron-skill）：

## 12. 常见问题与解决方案

### 12.1 安装与启动问题

#### Q1：安装失败，提示"安装包损坏"？

解决方案：

1. 重新下载安装包（确保从官网下载）
1. 检查网络连接，下载可能不完整
1. 关闭杀毒软件后重试（部分杀软误报）
1. Windows：右键安装包 →「属性」→「解除锁定」→ 重新安装
#### Q2：macOS 提示"无法打开，因为来自身份不明的开发者"？

解决方案：

1. 系统偏好设置 → 安全性与隐私 → 点击「仍要打开」
1. 或右键点击 QClaw → 选择「打开」→ 再次点击「打开」
#### Q3：首次启动一直显示"正在部署环境"？

原因：首次运行需要下载和配置 OpenClaw 运行环境（约 2-5 分钟）

解决方案：

1. 耐心等待，不要关闭窗口
1. 检查网络连接
1. 若超过 10 分钟仍无响应，关闭后重新启动
### 12.2 微信连接问题

#### Q4：微信扫码后提示"连接失败"？

排查步骤：

```text
① 确认电脑已启动 QClaw 且界面正常
② 检查网络连接（电脑和手机需在同一网络或均可联网）
③ 关闭 QClaw，重新启动
④ 删除微信中的 QClaw 助手，重新扫码绑定
⑤ 检查是否为最新版本的 QClaw
```

#### Q5：微信连接成功但发送消息无响应？

排查步骤：

```text
① 检查电脑 QClaw 是否在运行（底部有绿色状态指示）
② 检查 Token 额度是否充足
③ 查看 QClaw 操作日志是否有记录
④ 重启 QClaw 后重试
```

#### Q6：微信控制需要电脑一直开机？

是的，微信远程控制要求电脑保持开机状态。若要 24 小时待命：

- 建议将电脑设置为「从不睡眠」
- 或使用远程唤醒（WOL）功能
- 或选择企业微信（支持推送提醒，不依赖电脑实时在线）
### 12.3 模型与 Token 问题

#### Q7：提示 Token 不足？

解决方案：

| 方案 | 说明 |
| --- | --- |
| 等待次日重置 | 每日 0 点自动恢复 4000 万 Token |
| 开启省钱模式 | 设置 → 省钱模式，节省 30-50% |
| 切换到自定义模型 | 使用自己的 API Key（额度自付） |
| 精简指令 | 减少无意义的追问，一次说清楚需求 |

#### Q8：模型响应很慢？

解决方案：

1. 选择网络较好的时间段使用
1. 切换到响应更快的模型（如 qwen-turbo）
1. 减少上下文长度（开启新会话）
1. 检查是否开启了太多 Skill（部分 Skill 会影响响应速度）
### 12.4 技能（Skill）问题

#### Q9：Skill 无法触发？

检查项：

```text
① Skill 是否已安装（QClaw 设置 → 技能管理）
② Skill 是否已启用
③ 指令中是否包含 Skill 的触发关键词
④ 尝试用更具体的指令描述需求
```

#### Q10：安装了恶意 Skill？

预防措施：

- ✅ 只从 SkillHub 官方市场安装
- ✅ 开启「恶意技能筛查」功能
- ✅ 安装前查看 Skill 评价和作者信息
发现恶意 Skill 后：

```text
① 立即卸载（QClaw 设置 → 技能管理 → 卸载）
② 查看操作日志，确认是否有异常操作
③ 如有数据泄露风险，及时修改相关密码/Key
```

### 12.5 卸载与重装

#### Q11：如何完全卸载 QClaw？

Windows：

```text
① 关闭 QClaw（确保完全退出）
② 控制面板 → 程序和功能 → 找到 QClaw → 卸载
③ 删除用户数据（可选）：
   C:\Users\<你的用户名>\.qclaw
   C:\Users\<你的用户名>\.openclaw
④ 清理残留文件
```

macOS：

```text
① 关闭 QClaw
② 将 QClaw 从「应用程序」拖到废纸篓
③ 清理用户数据（可选）：
   ~/.qclaw
   ~/.openclaw
④ 清空废纸篓
```
